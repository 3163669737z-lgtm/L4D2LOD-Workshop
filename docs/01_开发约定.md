# 开发约定（给并行开发者 / AI agent）

> 所有参与本项目实现的人（或 agent）先读这份，再读 `docs/00_方案_设计与决策.md` 与对应模块的规格文档。

## 1. 工程与构建

- 工程根：`成品/02_L4D2工具/L4D2_LOD_Studio/`
- 目标框架：**.NET Framework 4.8**（net48），WPF，`LangVersion=latest`（C# 12）。
- 编译器：便携 .NET SDK 8（`C:\Users\TPP\.tools\dotnet-sdk-8.0.404\dotnet.exe`）。
- 构建（唯一方式）：
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File "<工程根>\build.ps1"
  ```
  末尾必须出现 `BUILD OK`，产物 `<工程根>\dist\L4D2LOD远景工坊.exe`。build.ps1 会把 exe 完整性级别修到 Medium（构建环境下默认是 Low，Low 进程写不了普通文件）。
- 不允许引入 NuGet 包 / 第三方 dll / 外部运行时依赖（除 .NET Framework 自带与系统 Blender）。
- 引擎层（`src/Engine/**`）**禁止**引用 `System.Windows.*`、`System.Windows.Forms.*`（保证 `--selftest` / `--batch` 能在无界面下跑）。
- 所有面向用户的字符串用中文；写入文件的数字一律 `CultureInfo.InvariantCulture`。

## 2. 测试

各模块用 `[SelfTest("用例名")]` 静态方法登记用例（`src/Engine/SelfTestFramework.cs`）：

```csharp
using LodStudio.Engine;

internal static class SelfTestMyModule
{
    [SelfTest("我的模块：xxx 行为")]
    public static void MyCase(SelfTestContext ctx)
    {
        string dir = ctx.NewDir("my_case");   // 每次调用得到独立临时目录
        // ... 造数据、调被测代码
        ctx.AssertEqual("期望", 实际, "说明");
        ctx.Assert(条件, "说明");
    }
}
```

运行（WinExe 需要重定向 stdout）：

```powershell
$env:L4D2LODSTUDIO_SETTINGS_DIR = Join-Path $env:TEMP 'lodstudio_selftest_cfg'
$out = Join-Path $env:TEMP ('selftest_' + [guid]::NewGuid().ToString('N').Substring(0,6))
$psi = New-Object System.Diagnostics.ProcessStartInfo
$psi.FileName = '<工程根>\dist\L4D2LOD远景工坊.exe'
$psi.Arguments = "--selftest --filter 我的模块 --out `"$out`""
$psi.UseShellExecute = $false; $psi.RedirectStandardOutput = $true; $psi.RedirectStandardError = $true; $psi.CreateNoWindow = $true
$p = [System.Diagnostics.Process]::Start($psi); $so = $p.StandardOutput.ReadToEnd(); $se = $p.StandardError.ReadToEnd(); $p.WaitForExit()
"exit=$($p.ExitCode)"; $so; if ($se) { "STDERR: $se" }
```

- 退出码 0 + `SELFTEST: N passed, 0 failed` 才算通过；结果同时写到 `$out\selftest.txt`。
- 测试必须只操作 `ctx.NewDir(...)` 下的临时目录或 `AppInfo.TempRoot`，**绝不碰用户真实工程/设置**。
- 与旧版行为对照时，旧项目根（只读参考）：`成品/02_L4D2工具/L4D2自动LOD工具/`；研究规格在 `<workspace>/.tmp/v6_research/spec_*.md`。

## 3. 代码约定

- 命名空间：`LodStudio.Engine`（引擎）、`LodStudio`（应用）、`LodStudio.Views`、`LodStudio.ViewModels`、`LodStudio.Cli`、`LodStudio.Services`。
- 一个模块一个文件夹；文件内部按"公开契约 → 私有实现"排列，公开成员写 XML 注释（中文）。
- 异常处理：库代码不吞掉"会导致用户数据错误"的异常；失败要返回可读中文错误（`QcWriteResult.Error` / `BlenderJobResult.Error`）。
- 文件写入：QC 用 `QcWriter`（内含原子写 + 备份）；模型/LOD 输出用 `FileUtil.WriteBytesSafe`。
- 资源释放：所有 `FileStream`/`Process` 用完即 `using`/`Dispose`；取消路径也要走 `finally` 清理。
- 不修改别人负责的文件；需要改共享契约（`src/Engine/**Contracts*.cs`、`src/Engine/Contracts.cs`、`src/AppInfo.cs`、`src/L4D2LodStudio.csproj`、`src/Themes/**`、`src/Views/ShellWindow.*`）时，在最终报告里说明，由主控统一改。
- 不得整文件复制旧项目源码；可以阅读旧代码理解行为，实现要自己写（对外协议/格式必须与旧版兼容）。

## 5. 验收硬指标（模块级）

- 构建 0 错误、0 警告（warning 要清掉）。
- 自测用例全部通过，且覆盖规格里的边界（编码/回滚/幂等/取消/超时/损坏输入）。
- 不修改用户真实文件（测试用临时目录）。
- 报告写清楚：改了哪些文件、关键决策、测试命令与真实输出、遗留风险。

## 附：踩坑记录（来自实现/评审阶段）

1. **WPF 绑定只能用属性**：`public string Text;` 字段不参与绑定，界面静默空白且无任何报错。凡是要给 XAML 绑定的成员一律写成属性。
2. **脚本文件编码**：`.ps1` 必须 UTF-8 with BOM（Windows PowerShell 5.1 否则按 ANSI 解析，中文注释/字符串会破坏语法）；`.py` 用 UTF-8 无 BOM；C# 源文件统一 UTF-8（无 BOM 亦可，含中文注释）。
3. **临时文件名要带路径哈希**：只按文件名生成临时产物，会在"不同目录同名模型"时互相覆盖（本次真 P1）。用 `FileUtil.ShortPathHash(绝对路径)`。
4. **编码探测要"无损才写回"**：任何"能解开就改"的宽容策略都会写坏 GBK/BOM 混乱的文件；正确做法是解码后重编码比对原字节，不一致就拒绝修改。
5. **DispatcherTimer 不保证准点**：动画/停留时间按真实经过时间计算。
6. **WPF 子元素 z 序 = 声明顺序**：需要盖住后面的兄弟元素时，显式 `Panel.ZIndex` 或调整声明顺序；不要指望"后加的会被盖住"。

7. **模态对话框不要在 Click 处理器里同步打开**：系统文件对话框的模态消息循环会让按钮的 `IsPressed` 状态卡住（关闭后仍显示"内凹"）。用 `Dispatcher.BeginInvoke(..., DispatcherPriority.Input)` 延迟到按钮完成按下/抬起后再弹窗口。
8. **焦点框要慎用**：`FocusVisualStyle` 与自绘焦点描边在点击后都可能残留"方框"；自定义控件只在**键盘**聚焦时画焦点框，按钮/列表行用 hover/选中态表达，不用焦点框。

9. **自绘文字要按基线对齐**：页签「文字 + 计数」这类组合，数字固定槽宽（如 26px）避免宽度随数字位数变化；绘制时用 `FormattedText.Baseline` 对齐而不是按行高居中，否则数字会看起来偏低。
10. **表头与行内容必须同一套边距**：表头有 16px 外边距时，行模板内容也要同样的 16px，否则列会错位；表格线用 1px 发丝、内容居中。
11. **列表取消选中**：`ListBox` 默认点空白不取消选中；在 `PreviewMouseLeftButtonDown` 命中不到 `ListBoxItem` 时 `UnselectAll()`，窗口级预览再补一层"点列表外取消"。
12. **删除校验提示后要留可发现性**：去掉红字提示时，「开始生成」等禁用动作要保留原因（ToolTip/状态文案），否则用户不知道为何不能点。

13. **数值联动优先在 ViewModel 里夹取**：距离递增 / 比例递减这类规则不要只做校验报错；输入回调里先夹到合法值（距离 ≥ 上一级+1，比例 ≤ 上一级-1 个百分点），失焦时再格式化显示。改前面的级别要级联修正后面所有级别。
14. **比例条要有上限**：拖条控件加 `Maximum` DP，绑定 VM 的 `MaxRatio`；拖动、键盘、代码写回都要夹取，否则会绕过约束。
15. **"铺满"不等于"按数量等分"**：LOD 级别行高应为 `(可用高度 - 表头) / 最大级数` 的固定值——添加/删除级别时控件大小位置不变，满级刚好铺满，少量级别正常留空；否则 4 级时行会被拉成两倍高。
16. **不要留自定义焦点框**：`Segmented`/`RatioBar` 这类自绘控件的焦点描边会被用户当成"不明方框"；要完全移除，输入框只保留中性边框。

17. **1px 外框线要显式画 + 关抗锯齿**：分数 DIP 坐标下的 Border 边线会被抗锯齿淡到看不见；把上/下外框线拆成独立 `Border Height="1" Background={LineStrong}` 并加 `RenderOptions.EdgeMode="Aliased"`；满级时底框线建议用 host 底部 overlay 绘制，避免被最后一行行线覆盖。
18. **面板分隔线要通栏**：表头/工具行分隔线不要加左右 16 边距，否则用户会看成"没顶到头"。
