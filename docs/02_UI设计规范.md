# UI 设计规范（远景工坊 v7）

> 所有界面实现者（人或 AI）以此为准。涉及具体数值时**以本文为准**；新增控件状态要在这里补一行。
> 定位：**测距仪 / 量具**——精密仪器的正面板，不是数据后台。所有装饰必须回答"这是量测信息吗"。

## 1. 设计语言

- 两种机身：**日测（浅色）** 冷纸白 + 石墨字；**夜测（暗色）** 石墨黑 + 冷白字。
- **直角**：所有控件、面板、浮层 Radius=0；没有模糊阴影。浮层（Toast/菜单/对话框）用 **3px 硬偏移色块** 代替阴影。
- **1px 发丝线** 是唯一的分隔手段；面的层级：Canvas（画布）→ Panel（面板）→ Sunken（输入/凹槽）。
- **唯一的信号色**（浅 `#B5460A` / 暗 `#FF7133`）只用于三件事：**动作**（主按钮）、**当前**（选中行左条 / 当前页签下划线 / 焦点环）、**进度**（进度条 / 运行状态）。绝不用在标题、普通图标、装饰线、静态边框上。
- **刻度语言**只在两处出现：顶栏底边的刻度规（`TickStrip`）与 LOD 阶梯图的坐标轴。不滥用。
- **角标**：四角方括号（`CornerBrackets`）只挂在"作业队列"面板（当前主作业区）。
- **编号**只用于真实有序处：队列序号、LOD 级别 01–08、日志序号；不做装饰性编号。
- **单语标题**（第六轮按反馈调整）：所有面板头只保留中文标题，删除 `JOBS` / `LADDER` / `STREAM` 及 logo 旁的 `FARSIGHT`、空状态的 `EMPTY QUEUE` / `NO MATCH`；不再出现"英文小标对不齐"的问题。
- 中文 = Microsoft YaHei UI；数字/拉丁 = Bahnschrift；路径/日志/代码 = Consolas。**不要 `new Font()` 自造字号**，用 `Typography.xaml` 里的样式。

## 4. 尺寸与间距

- 间距阶梯：**4 / 8 / 12 / 16 / 20 / 24 / 32**；页边 20；面板内边距 16；面板间距 14。
- 窗口：默认 **1320×860**，最小 **1120×720**；自绘标题栏（`WindowChrome`，CaptionHeight=56）。
- 骨架：顶栏 56（含底部 7px 刻度规 + 1px 线）｜主体（左队列 + 14 间距 + 右 LOD 400）｜日志（折叠 44 / 展开 200，默认折叠）｜HUD 68。
- 左列：作业队列（行高 56、表头已删除只留 1px 分隔线、面板头 40、工具行 44、页脚 28）在上，日志在下，间隔 12。
- 右列 LOD 面板：面板头 40 / 级别表格（表头 26 + 行高**固定 40**）/ 添加一级 32 / 写入方式 66 / 高级入口 48。
  - 级别表不铺满：4–8 级都按实际行数排列，下方正常留空；8 级也不会把行拉高。
  - 第二轮打磨移除了原 140 高阶梯图（用户反馈顶部比例条冗余、此前拖拽无效），LOD 参数改为纯数值表 + 比例条。
- 队列列宽：序号 40 · 类型 64 · 名称/路径 `*` · 规模 96 · 状态 92 · 操作 56；**表头与行同边**。
- LOD 列宽：级别 34 · 距离 **82** · 比例条 `*` · 比例 **82** · 删除 28；数字框内文字**水平居中**（原先右对齐 + `%` 浮标叠字，已修正）。
- 按钮高度：HUD 34、设置页 32、行内图标按钮 24–28；所有像素用 WPF DIP（`AutoScaleMode` 不存在，DPI 由 WPF 自动处理），不要写死设备像素。

## 5. 区域规格

### 5.1 顶栏
左：品牌标记（24×24 矢量：递降阶梯 + 顶部测线 + 远点）+「远景工坊」15.5 半粗 + `v7.0` 微标（**不再有 FARSIGHT、分隔线、工程上下文两行**，第六轮按反馈删除）。右侧只有环境灯 + 主题/菜单/窗口按钮。
右：**一个**环境状态（5px 方点 + 文字 10.5 + 右箭头：绿=环境正常 / 红=环境异常 / 灰=检测中），tooltip 列出 Blender/编译器/权限三项明细，点击打开「运行环境诊断」；主题切换（34×34，太阳/月亮图标）；菜单（34×34，点击开关、再点收起）；竖分隔；最小化/最大化/关闭（42×40，关闭 hover 红底）。
底边：`TickStrip` 7px（Step 8、每 5 长）+ 1px `Brush.Line` 通栏。

- 工具行（第四轮调整）：5 个页签 `全部/未完成/完成/异常/跳过`（`Segmented` Tabs，11px、ItemPadding 9）｜**中间留空**｜**靠右的搜索框** 204×30（放大镜 + 占位「搜索任务」+ 有文字时 ×）。
  - **顶部不再放导入按钮**：导入入口只保留三处——空状态的两个按钮（「导入文件夹」「导入文件」，都是带边框的 Secondary、34 高）、队列右键菜单、☰ 菜单顶部两项。QC / GLB / SMD 统一走「导入文件」（多选）。
  - 1120 最小窗口下页签与搜索不重叠（`--ui-audit` 布局断言覆盖 1120×720）。
- 表头：已删除（第七轮反馈：去掉那一行文字，只保留一条 1px 分隔线分隔文件列表；第八轮把这条线改为**通栏**，左右顶到面板边缘）。
- 行（56）：序号（Numeric 12.5 弱色右对齐）｜类型（14px 图标 + 10.5 文字）｜名称 12.5 + 路径 10.5 Mono 弱色（两行，超长省略）｜规模 11.5｜状态（5px 方点 + 11.5 文字，色调随状态）｜操作（显示/移除两枚 24×24 图标按钮，静息 0.28 透明度，行 hover 变 1）。
- 状态色：完成/全部跳过→Ok，部分完成/已停止→Warn，失败→Err，运行中→Signal，其余→InkFaint。
- 选中：行底 `RowSelected` + 左边缘 2px 信号条；hover：`RowHover`。
- 空状态：`TickStrip` 150 + 「队列为空」PageTitle + 一行说明 + 两个按钮（「导入文件夹」「导入文件」，均为带边框 Secondary，34 高），整体垂直居中。
- 无匹配：`没有匹配的任务` + 说明 + 「清除筛选与搜索」Ghost 按钮。
- 页脚：`上次运行：刚刚 · 4 完成 · 1 失败` Micro + 右侧「查看报告 ›」（Bare 按钮，无报告时禁用）。
- 计划视图（覆盖列表区）：头「作业计划 / PLAN」+ 右侧「返回队列」；摘要两行（Headline 11.5 / Subline 10.5）；行 44：动作（生成=Ok/跳过=Faint/错误=Err）｜QC 名 + 原因（Micro 弱色）｜模型摘要｜任务数；底部按钮「返回队列」Ghost +「按此计划开始生成」Primary（无处理项时禁用）。

### 5.3 LOD 方案

- 面板头：只有 `LOD 方案`；右侧预设下拉 172×30 + 「恢复」Bare（仅参数被改且能找回原预设时可用）。
- 级别表格：上/下外框线与左右边框分开绘制（`LineStrong` 1px，`RenderOptions.EdgeMode="Aliased"`）+ 表头 26（级别 / 距离 HU / 保留比例 / 比例 %，各格居中、列间 1px 分隔）+ 行高 **固定 40**；每格都有右侧分隔线，序号/数值全部水平垂直居中，行底 1px 分隔线。8 级时底框线用 host 底部 overlay 绘制，保证可见。
  - 距离输入框、比例输入框内层无边框、背景透明，单元格在 hover/焦点时用 `RowHover`/`Sunken` 背景提示；输入**即生效**（`UpdateSourceTrigger=PropertyChanged`），不需要回车。
  - 比例条在单元格内居中，6px 轨 + 8×14 把手，拖动实时写回。
- 添加一级：表格下方整宽 Secondary 大框（36 高、文字和 `+` 居中），8 级时隐藏。
- 分隔条：添加一级与写入方式之间、写入方式与高级参数之间各一条 1px 发丝线。
- 写入方式：标签 10.5 + `Segmented` Boxed 三选（原 QC / 独立 _LOD.qc / 仅合集），`EqualWidths` 铺满整行。
- 高级参数：整宽 Secondary 带外框按钮（38 高），文字居中，「高级参数」+ 右侧 `›`。
- **第五轮移除**：顶部规格摘要行、红字校验提示、「已修改」角标（按反馈删除；参数不合法时仅「开始生成」禁用）。
- **第六轮调整**：
  - （第六轮历史方案，已被第七轮取代）：级别表曾用 `VerticalFillPanel` 按当前级数等分铺满；第七轮改为固定"可用高度/8"的行高，避免 4 级时被拉成两倍高。
  - 数值联动：距离不小于上一级 → 立即按"上一级 +1"生效；比例不小于上一级 → 立即按"上一级 -1 个百分点"生效；改前面级别时逐级级联修正。
  - `RatioBar` 新增 `Maximum`（= 上一级比例 - 1 个百分点，第一级为 100%），拖动/键盘都不会越界。
  - 距离/比例输入框：点所在单元格以外任意位置 → `ClearFocus()` 并整理格式（与搜索框同一套失焦逻辑）。
  - 删除全部自定义焦点描边（`Segmented` / `RatioBar` 的键盘焦点框一并删除），彻底消除"点击后残留方框"。
  - 队列表头：删除表头下的 1px 分隔线，表头行 28→24，列表整体上移。
- **第七轮修正**：
  - 级别行高 = `(LOD 表格 host 实际高度 - 26) / 8`；添加/删除级别时行高**不变**，8 级刚好铺满，4–7 级下方正常留空（不再按当前级数等分拉高）。
  - 队列表头那一行文字整体删除，只留一条 1px 分隔线。
- **第八轮修正**：
  - 队列表头分隔线去掉左右 16 边距，改为通栏，和面板内其它分隔线一致。
  - LOD 级别表格改为"上/下外框线单独画 + 左右边框"的结构；8 级满级时底框线画在 `LodTableHost` 最底部（overlay），不会再被最后一行行线覆盖；关键 1px 线加 `RenderOptions.EdgeMode="Aliased"`，避免 150% DPI 下因分数坐标被抗锯齿"吃掉"。

## 6. 动效预算

- 只做**状态反馈**：hover 120ms、press 立即、面板展开 180ms、Toast 200ms、进度条数值 200ms、设置「已保存」900ms、对话框 120–160ms。
- **不做**：入场编舞、逐字擦入、扫描线、粒子、视差、循环装饰动画。
- 所有动画都必须尊重 `SystemParameters.ClientAreaAnimation` 与 `settings.Animations`；关闭时立即到位（不要在动画回调里做必要逻辑）。
- 不要在 `OnRender` 里启动 Timer；动画不要阻塞 UI 线程。

## 7. 可访问性与键盘

- 所有可点元素：hover / press / focus（键盘焦点环 = 1px 信号色内缩边框）/ disabled（38–42% 不透明度，不给 hover）/ cursor 手型。
- Tab 顺序 = 视觉顺序；对话框内 Tab 循环；Esc 语义分层：关对话框 → 停止运行 → 清筛选/搜索。
- 快捷键：F5 开始 / Esc 停止 / Ctrl+O 加 QC / Ctrl+Shift+O 加工程 / Ctrl+F 搜索 / Ctrl+L 日志 / Ctrl+, 设置 / Ctrl+A 全选 / Delete 移除 / Ctrl+↑↓ 排序 / Enter 详情 / F1 快捷键。
- 文本对比度：正文 ≥4.5、大字与非文本 ≥3（由 ui-audit 表验收）。

## 8. 截图验收（`--ui-audit`）

状态矩阵（浅/暗各一套）：空队列、有任务、运行中、完成、失败、无匹配、计划视图、日志展开、设置 5 页、确认框、输入框、Toast 三色、菜单、拖放高亮、8 级 LOD、最小窗口、宽屏。
判定：
- 浅→暗→浅 逐像素往返 = **0 差异**；两主题差异 > 90%（证明整体换色）。
- 布局审计：兄弟控件无重叠、无越界（滚动区内容除外），至少覆盖 主窗口 1280×840 / 1600×900 / 最小 1120×720 + 设置窗口浅暗，共 5 组。
- 对比度表全部达标。`Brush.Line`（发丝分隔线）属装饰、不计入 1.4.11 必需边界；`Brush.ChartGrid` 在色带上仅作辅助网格，记为 NOTE；`Brush.LineStrong` 必须 ≥3:1（输入边框/浮层边框/强调分隔）。
- Toast 与 HUD/日志矩形不相交；对话框默认焦点符合上文。
- 三档缩放（100/125/150，用 `LayoutTransform` 模拟）无截断/重叠。
- 鼠标点击后不留焦点框；菜单点一次开、再点收起；设置页主题/动效只在外观页出现。

## 附：实现期补充约定（评审收口后）

1. **WPF 绑定只能用属性**：ViewModel 里给模板绑定的成员必须是 `{ get; set; }` 属性；字段绑定不会报错但界面静默空白（本次修了日志正文与计划行两处）。
2. **覆盖层层级**：内容区内的覆盖层（计划视图）用 `Panel.ZIndex` 显式抬高；`DialogHost` / `ToastHost` 必须保持在窗口根 Grid 的最后，永远在最上层；对话框打开时允许遮住标题栏（模态语义）。
3. **动画与真实时间**：Toast/Dialog 的进退场、停留时间一律用 `Stopwatch`/真实 delta 计算，不按 tick 计数（`DispatcherTimer` 在离屏/软件渲染下会慢 1.5~2 倍）。
4. **截图工具**：`UiCapture.CaptureWindow` 固定 1:1 逻辑像素（96 DPI）。要"高 DPI 视觉压力"截图时，先把窗口尺寸设为目标逻辑尺寸 × scale，再截图。
5. **图表标签**：`RangeCard` 控件已从主界面移除（保留给 `--widget-preview` 设计核对）；其百分比标签规则仍为「优先台阶上方、窄段回退到色带内左上」。
6. **日志面板**：展开时队列区收缩、日志区占满底部；折叠箭头 `RenderTransformOrigin=(0.5,0.5)`。日志正文用等宽字体、正文列 `TextTrimming` 省略 + ToolTip。

## 9. 第二轮细节打磨（2026-11-15，已实施并机检）
